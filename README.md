# morning-intel-widget

Daily financial/markets brief, published each morning at 8:30 (Europe/Paris) by a Claude Code routine, and rendered on an iOS home screen via a [Scriptable](https://scriptable.app) widget.

- `latest.json` — the current day's brief, overwritten each morning.
- `widget.js` — the Scriptable script that fetches `latest.json` and renders it as a home-screen widget.

Raw feed URL: `https://raw.githubusercontent.com/TimoteoAdrogue/morning-intel-widget/main/latest.json`
